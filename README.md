# Domain Inspector

A C++ command-line networking utility that inspects a domain
and retrieves publicly available DNS, IP, hostname, and
network information using low-level socket/networking APIs.

## Usage:
- compile:
  `g++ --std=c++23 -Wall showip.cpp -o showip`

- run:
  `./showip abc.com`
